# Student Manager

A simple Java application that manages student records using PostgreSQL and JDBC.

## Technologies
- Java 21
- PostgreSQL
- JDBC
- mvn

##Project Versions

### 1. Spring Boot REST API (main)
- Java 21
- Spring Boot
- Spring Data JPA
- PostgreSQL
- Maven

### 2. Plain Java + JDBC (task1)
- Java
- JDBC
- PostgreSQL


## Database Setup
1. Create a PostgreSQL database named `training_db`.
2. Run the SQL commands in `database/database.sql`.

## Database Configuration
Update the database username and password in `DatabaseConnection.java`.

## CRUD Operations
- Create a student
- Get all students
- Update a student
- Delete a student

## How to Run
1. Open the project in IntelliJ IDEA.
2. Make sure Java 21 is configured.
3. Make sure PostgreSQL is running.
4. Run `Main.java`.


## Running the Application

Run `StudentManagerApiApplication.java` from your IDE.

The API runs at:

`http://localhost:8080`
